Tarea 5: Análisis de Clustering del Dataset LaRS
Este proyecto implementa un análisis de clustering no supervisado para descubrir las estructuras naturales presentes en el dataset de escenas acuáticas LaRS.

El notebook detalla un pipeline completo de preprocesamiento, incluyendo One-Hot Encoding, StandardScaler y Análisis de Componentes Principales (PCA). Se realiza una comparación sistemática de múltiples algoritmos de clustering (K-Means, Gaussian Mixture, MeanShift, Birch, DBSCAN), evaluados mediante el Coeficiente de Silueta.

El análisis concluye que los datos se agrupan de forma natural en tres clusters cohesivos e interpretables: "ríos", "mares" y un grupo "híbrido" intermedio.
